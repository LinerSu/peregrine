# Track applications

**Goal:** keep one clear list of everything you've applied to, with status and notes.

Open the **Applications** tab.

## What's there

Every job you mark applied shows up here with its **company, position, status, applied date,
interview date, salary, contacts, and notes**. Edit any field inline:

- Change **status** from the dropdown — `applied → interviewing → offer → rejected → closed`.
- Set an **interview date**, jot **contacts** and **notes**.

The **Insights** tab turns this history into patterns (e.g. where you're getting traction).

## Add an application you applied to elsewhere

Two buttons at the top of the Applications tab:

- **+ Add** — a quick manual form (company, position, status, date, …). Use it when you just
  want a row.
- **+ From posting** — paste the job text, upload a **PDF**, or give a **URL**. Peregrine
  parses it into a tracked job *and* logs the application in one step — so it's linked, not an
  orphan. Best when you have the posting handy.

## Orphans

If an application has no linked job posting, the row shows a **⚠ add posting** badge. Click it
to attach the posting (paste/PDF/URL) — then you can evaluate fit and tailor a CV for it like
any tracked job.
